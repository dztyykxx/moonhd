## 4. 视觉规范

风格：克制的天文仪器感。保持月球为视觉中心，面板不覆盖默认整球的主要区域。避免夸张光晕、霓虹、虚构仪表或无意义数据。

| Token | 值 | 用途 |
| --- | --- | --- |
| background | `#06080B` | 场景后备背景 |
| panel | `#121519F0` | 深色半透明面板 |
| border | `#FFFFFF1C` | 1px 细边框 |
| text | `#EEEDE9` | 主要文字 |
| muted | `#979CA3` | 次要文字 |
| accent | `#C8AA73` | 选中、定位、重点 |
| active-fill | `#C8AA731A` | 轻量选中背景 |

中文使用系统字体栈，优先 PingFang SC，后备 Noto Sans SC / Microsoft YaHei；坐标用等宽数字，可用本地可用字体，不依赖 Google Fonts 在线请求。设计稿的字体只是视觉参考。

- 标题 22–26px，正文 13–14px，次级信息优先 12px；辅助来源可为 11px。
- 间距采用 4/8/12/16/20/24/28px；面板圆角 12px，控件圆角 8px。
- 常用按钮高度 40px，移动端触控目标至少 44px；不要把图标实际尺寸等同于可点击区域。
- 面板背景适量模糊，弱设备可降级成实色。保持文字对比度和焦点可见。
- 选中用金色边框与淡背景，不铺满金色按钮。
- 显隐动效 160–220ms；地点飞行约 600–900ms，可被拖拽打断；尊重 reduced-motion。
- 纯图标按钮必须有可访问名称和简短提示，不使用 emoji 代替正式图标。

## 5. 布局与响应式

桌面参考画板 1440×900：外边距约 28px，顶栏高 44px；左右普通面板宽约 264px，设置面板宽 328–352px；底部观察工具栏高 62px，坐标栏高 40px。具体高度随内容调整，不得截断文字。

- 桌面宽度 ≥1200px：左右侧栏可同时显示。面板打开时应确保月球主体有足够可用区域。
- 768–1199px：左右面板择一展开，保留搜索和紧凑工具栏，避免两面夹住月球。
- <768px：单个底部抽屉，地点/设置复用；手机参考 390×844。抽屉收起、半屏、展开三个状态；展开过高时内部滚动。
- 手机上的月球按可用视口适配，不能机械复制设计稿的图像裁切比例。完整观察模式应能看见整球。
- 适配 safe-area，横屏和短高度窗口也不能让控件超出屏幕。
- 单个侧栏关闭时保留相应展开入口；入口本身也可被可见性设置隐藏，仍有全局恢复手段。

## 6. 所有 UI 都可以隐藏

这是硬要求，不只是两个侧栏可以收起。

可见性设置至少覆盖：顶栏与搜索、地点目录、信息卡、坐标状态栏、观察工具栏、缩放工具、地名和选点标记、自转轴与极点标签、经纬网与坐标标签。

需要区分两类状态：

1. 用户偏好：单独勾选各区域是否显示，按版本化 schema 保存到 localStorage。
2. 临时沉浸：临时隐藏所有 UI 和地理辅助覆盖层，但不覆盖保存的偏好；退出后恢复原来的组合。

隐藏 UI 不改变曝光、画质、月相或高清加载策略。隐藏自转轴不停止自转；关闭自转不隐藏轴线。关闭星空、彩色等是改变场景图层，和隐藏控制它们的 UI 不同。

恢复入口：

- `H` 切换完整界面/沉浸，但输入框、可编辑内容和组合输入期间不触发。
- `Esc` 优先退出搜索浮层或当前弹层；没有弹层时退出沉浸。
- 沉浸状态不常驻恢复按钮。鼠标靠近底部或触屏轻触空白处时，显示“显示界面”按钮约 2.5 秒。
- 轻触须与拖拽区分，不能旋转月球时不断弹出按钮；该次恢复轻触不同时选点。
- 恢复按钮是可聚焦控件；键盘焦点在隐藏面板内时，隐藏操作必须把焦点转移到安全位置。
- 即使用户单独关闭了所有面板，也能通过全局恢复入口打开可见性管理或恢复默认布局，不能出现无法操作的死角。

## 7. 月固坐标、选点与定位

### 坐标契约

统一：纬度北正南负，范围 −90°…90°；经度东正西负，内部规范化为 `[-180,180)`。输入接受 `纬度, 经度`，可扩展 N/S/E/W 形式；带符号与方向矛盾时提示错误。展示使用 N/S/E/W，并避免 −0。

当前渲染系为 **y 轴指向北极**：

```text
local = (cos(lat)cos(lon), sin(lat), −cos(lat)sin(lon))
lat = asin(normalizedLocal.y)
lon = atan2(−normalizedLocal.z, normalizedLocal.x)
```

`hips/healpix.js` 的 HEALPix 内部为 z 极轴，已有 `hpToRender` / `renderToHp` 边界。复用现有约定，不能把天文坐标向量直接传给月球渲染或标注。

世界空间射线命中后先通过 `moon.matrixWorld` 的逆矩阵转换到月球局部，再算经纬度。选择底图球面或统一解析球面进行拾取，不遍历所有 HiPS 瓦片；目前底球半径与细节球半径略有差异，需一致处理并归一化。

### 三种坐标

- 视野中心：屏幕中心射线与月球的近交点。未命中时为 `—`，不能拿相机正下方点冒充。
- 指向位置：鼠标在月面上时更新，移到星空、UI 或离开画布时清空。节流至约 20Hz，不必每帧更新 DOM。
- 选中点：点击固定，独立于视野中心和鼠标位置。任意点不保证有地名，未匹配就显示“月面位置”。

地名目录中的中心坐标不等于点击的坐标。近邻搜索只能提示“附近地点”，没有明确范围数据时不能断言用户正处在某月海或坑内部。

### 交互

- 指针位移超过合理阈值（例如 5 CSS px）视为拖拽，不选点；兼容触控、多指和 pointer cancel。
- 点选后出现标记、选中点卡片、复制坐标动作。标签随三维位置投影，在背面或被遮挡时隐藏，不透视穿过月球。
- 搜索支持中文别名、正式名称、任务名称和经纬度；本地匹配，约 150ms debounce，键盘上下选结果、Enter 定位。
- 搜索没有结果、格式无效、超范围都有行内提示；不要静默把纬度裁到边界。
- 通过用户操作复制坐标，成功/失败给轻提示；不要读取用户原有剪贴板。
- 飞到地点：经纬度→局部方向→月球世界变换；平滑变换相机，保留合理北向并确保相机不穿球。飞行过程暂停自转，用户拖拽可取消。
- 确保选点、搜索定位和地标标签在自转、旋转、缩放后仍与底图和细节一致。

## 8. 自转轴与经纬网

自转轴必须实现，提供独立开关。首版默认为关闭以保留干净画面；05 展示开启效果。用户后续若偏好默认开启，只需调整默认值。

- 轴线对应月球局部 ±Y 极轴，跟随 `moon` 的世界变换；不是固定屏幕竖线，也不是太阳光方向。
- 两端略伸出球面约 10%–15%，细线、低亮度金色；提供 N / S 或北极 / 南极标注。
- 用深度遮挡隐藏穿过球体的线段；避免粗线贯穿地貌。极点标签依据可见性显示，近距时可自动减少标签。
- 不展示没有天文模型支撑的实时倾角、真实时间或轨道位置。当前自转是浏览演示速度。
- 经线与纬线由月固坐标生成三维曲线，略高于表面，按真实球体遮挡；不能把 Pen 中的椭圆硬编码为屏幕线条。
- 整球可从 30° 间隔开始，近距逐级减小。限制线段/标签数量，添加缩放滞回，避免细节画面变成密网。
- 经度线在 ±180° 处连续，极点不出现重复线团；标签去重、避让地名。
- `A` 切换轴线，`G` 切换经纬网；输入焦点内不触发。沉浸临时隐藏两者，退出后恢复。

## 9. 观察设置和数据状态

保留当前功能：模拟月相、曝光、地形光照强度（原“起伏”）、底图自动/2K/4K/8K、自转、星空、地球反照、国内高清细节、彩色调制、亮度标定、清理缓存。

- 默认工具栏只暴露自转、自转轴、经纬网、月相和沉浸。其他选项收进设置。
- 04 是设置总览，09/10 是对应子面板。同一时间只展开一个右侧设置面板。
- 曝光和地形光照用真正的 slider，支持键盘方向键，有标签和数值；“起伏”不能暗示当前球体有真实位移地形。
- 高清使用已有整球底图、放大按需接入策略，最高 L7；UI 改动不改变进入/退出阈值和网络约束。
- 底部状态优先显示“8K 底图”“高清加载中”“高清已就绪”“暂用底图”；缓存/帧率/层级只在高级面板展开时更新。
- 画质切换和缓存统计都来自实际运行状态，不硬编码设计稿的 60 FPS、24/24 或缓存容量。
- 清理缓存必须仅清理本程序的瓦片缓存，给结果反馈；不能清掉其他站点数据或 UI 偏好。
- 影像署名放进“数据来源”并保留易找到的入口，不能因为沉浸模式永久删掉出处。

### 模拟月相的限制

当前 `setPhase()` 只是调整场景光源角度，不是带日期的天文历算；任意相机视角下，观察到的亮暗比例也不同。面板标题必须是“模拟月相”或“模拟光照”。

预设“新月/上弦/满月/下弦”应定义参考观察方向：若使用这些名称，先平滑回到固定正面参考视角，再应用相应光源；也可只显示角度预设。不要沿用 `180° = 满月` 的文字却在当前模型朝向下呈现半月。实际可见亮面比例若未计算，就不要把旧公式的百分数标成当前观测值；显示角度即可。

不在本轮声称“今日月相”“实时日照”“地球当前方向”。真实天文模型作为后续独立需求。

## 10. 地点与月球资料

首版精选约 20–40 个地点即可，不用接入整个地名数据库。至少覆盖月海、陨石坑、正面/背面和几处着陆点。设计稿只有部分样例，数据收录规模不受样例行数限制。

建议数据字段：稳定 id、类型、中文展示名、正式名称、别名、latDeg、lonDeg、可选 diameterKm、短简介、定位缩放建议、sourceUrl、sourceDate。着陆点另有 mission 和 landingDate，不强制套入“直径”字段。未核验的字段省略或显示 `—`，禁止编造。

正式地貌名与参数查 [IAU / USGS 月球地名目录](https://planetarynames.wr.usgs.gov/Page/MOON/target)。其[字段说明](https://planetarynames.wr.usgs.gov/Page/Specifics)用于确认坐标符号与字段含义。目录声明地貌中心坐标通常展示两位小数，边界用于定位，不代表严格地质单元范围；前端不要声称科学测绘精度。

任务地点查 NASA 或中国探月工程的官方资料。中文名作为维护的展示别名，不把自动翻译当成官方名称。NASA、USGS 地貌资料和任务资料各自保留对应来源链接。

月球概览参考 [NASA Moon Facts](https://science.nasa.gov/moon/facts/) 与 [NASA Moon Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/moonfact.html)。参考值与时间变化值分开；显示“平均地月距离”而非“当前距离”。月球概览给简短解释，不增加大段百科正文。

数据整理成小型本地 JSON，运行时无需依赖外部搜索服务。地名数据来源与影像数据来源分别注明，不新造许可结论。

法线纹理不等于可查询的 DEM。本轮不显示某点海拔、坡度、坑深或 7 米地形；图像分辨率也不能称为坐标精度。

## 11. 比例尺和方向

方向指示中的北向从月球北极方向在屏幕上的投影计算，不能固定写一个永远向上的 N。退化视角下隐藏或降级。

比例尺只表示视野中心附近的局部尺度。沿屏幕横向取两个邻近像素射线，求月面交点，用月球参考半径和球面角距估算公里数；动态选 1/2/5 系列整洁刻度。任一点未命中、接近月缘导致估算不稳时显示 `—` 或隐藏。不能用固定相机高度宣称整个透视画面都是同一比例。

可视尺度须与数据采样尺度区分：设计稿“500 km”是示例；L7 ≈28 m/px 描述影像采样，不是当前屏幕每像素多少米。

## 12. 实施顺序与代码边界

1. 基线：运行现有 `npm test`，记录默认整球/近距截图和高清请求情况。只读理解 `public/src/main.js` 与 `hips/` 坐标和状态。
2. UI 外壳：调整 `public/index.html` / `public/src/style.css`；按稿实现布局、面板、响应式、统一控件和完整隐藏/恢复。
3. 坐标与辅助线：提取小型 geo 模块，实现拾取、坐标格式、轴线、经纬网、方向与局部比例尺。
4. 地点探索：本地精选资料、搜索、信息卡、投影标签与相机飞行；处理自转暂停和恢复。
5. 接通既有设置和运行数据，核验模拟月相预设；补异常反馈、触控和键盘操作。
6. 验收：浏览器实际截图、网络和功能验证，更新 README，记录资料来源及未解决限制。

可自行决定模块命名，例如 `src/ui/`、`src/geo/`、`src/data/`；不要为简单状态搭建大型事件总线。地理转换只维护一套函数，多个入口不重复公式。

偏好持久化失败时回退默认状态，不影响观看。所有覆盖层只在状态/视角变化时更新，DOM 数值适当节流；不能为每个地名每帧频繁查询布局。

## 13. 验收要求

### 功能与数据

- 经纬度转换：四个基准经度、两极、±180° 附近，及独立已知地貌位置；不只测自身正反函数互逆。
- 用至少 3 个已核验地点检查标签、点击坐标、搜索定位与影像配准；至少包含南半球与背面。
- 自转、任意旋转、缩放之后坐标与地名仍正确，背面标签不透出。
- 拖拽不选点，点击 UI 不选点；指向星空不沿用旧坐标；中心未命中显示空值。
- 搜索结果、无结果、非法坐标、复制反馈、飞行取消均可复现。
- 自转轴沿本地极轴，开关不影响自转；网格随球体变换且无背面透视。
- 所有面板和标注可分别隐藏；关闭所有后仍能恢复；沉浸退出恢复原有偏好组合。
- H/Esc/A/G/Space 不干扰输入框与中文输入。Space 的默认页面行为在适用时处理。
- 模拟月相预设与参考方向吻合，没有把模拟值说成真实当前月相。

### 视觉与设备

- 至少查看 1440×900、1280×720、390×844、手机横屏；没有溢出、月球被控制面板完全遮住、按钮挤成两行的问题。
- 01/04/05/06/11/12/13/15 对应状态提供实际运行截图。其他选项提供交互记录或补充截图。
- UI 关闭后是实时场景，不能用静态设计截图伪装成效果；设计稿静态标记在产品中必须由真实坐标驱动。
- 键盘可操作、焦点可见、按钮有名称，手机恢复入口可触达。

### 渲染与网络回归

- 原有测试继续通过；坐标、输入解析、可见性恢复等新增逻辑有必要的针对性测试。
- 整球仍不请求高清 PNG，放大后仍正确按需加载；重访缓存命中正常。
- 弱网/离线继续显示底图，UI 不被长时间全屏等待遮住。
- 对照相同视角记录 UI 开/关帧率或帧时间及请求量，定位明显性能回退；不要求虚构固定 60 FPS。
- 不擅自把此次 UI 工作变成瓦片系统重写、全量下载或地形升级。
